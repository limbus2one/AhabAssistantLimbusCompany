# 英文卡包观测

在队伍设置的「观测卡包（英文）」中启用功能，按第1–5层选择目标。列表显示零协会中文译名和英文全名。目标必须在当前 Normal / Hard 楼层的观测列表中；留空的楼层按原有卡包权重选择。观测所需的星光由游戏显示并扣除。

配置示例：

```yaml
observe_theme_pack: true
observe_theme_pack_selected: ['1007', '1206', '', '', '1128']
```

进入选包页后，脚本先核对实际难度，再打开 Pack Search 和观测列表。从列表顶部按五列地图导航，用卡面匹配定位目标。点击前重新截图核验，点击后检查目标金色边框和可用 Confirm 按钮，再处理二次确认。返回选包页后重新识别目标。目标已经在选包页时直接复核，不重复观测。

英文卡包选择使用图片匹配：继承原有默认/自定义权重、刷新次数和第5层活动包设置，只选择通过匹配的卡包。拖动前再取新截图确认编号，拖动后确认到达镜牢地图。观测失败时按已识别卡包的权重选择；没有可靠识别结果时停止。

## 素材和精度检查

[catalog.json](../../theme_packs/catalog.json) 是名称、可用楼层和观测顺序的统一来源。95种图鉴卡面从模拟器截图取得，源截图先归一化为2560×1440，再裁出192×356素材。图鉴和选包页渲染不同的卡面另存选包截图模板；同编号的多个模板只占一个候选结果。

使用灰度归一化互相关比较封面主体和英文名称，排除挂钩、观测图标、饰品和选中边框。最佳分数至少0.90，并且领先另一编号至少0.03。定位指定模板后仍与全部编号比较复核。新卡包、相似封面或截图不稳定时拒绝命中；英文选包没有 OCR 兜底。

选中后的卡面允许目标宽度有±1像素栅格误差；每个尺寸仍需通过0.90分数、0.03不同编号间隔和金色边框检查。该处理来自Normal第4层1319真实选中截图的回归，不降低匹配阈值。

95张素材的自匹配只检查资源完整性。真实选包截图、错误目标、缺失名称、空白截图和金色选中边框另做回归检查，不能据此宣称所有卡包均已完成实机验证。

## 复现实验

在项目目录激活 `aalc`，确认配置的模拟器端口、实例、队伍和英文游戏语言正确。脚本直接调用现有 `init_game()` 和 `Mirror.run()`，由现有逻辑完成登录、预备、导航和战斗，仅在观测与选包函数处插入接管。

```powershell
conda activate aalc
# 观测后在第2层选包入口停止
python scripts/verify_theme_pack.py --target 1206 --target-floor 2 --observe-only
# Hard 第2层观测、复核、拖动，确认进入地图后停止
python scripts/verify_theme_pack.py --hard --target 1204 --target-floor 2 --stop-floor 3 --select-only
# 第1层观测并继续调用原脚本战斗，到第2层选包入口停止
python scripts/verify_theme_pack.py --target 1007 --stop-floor 2
```

未到目标层时由原脚本前进。`--observe-only` 在遇到的第一个选包入口停止；`--stop-floor` 在指定层选择前停止，`--select-only` 优先于停止楼层，在第一次拖动后的地图处停止。已有镜牢进度会继续，遇到已有结算奖励时立即停止。

实验记录写入 `logs/theme_pack_experiment/run_<时间>/`，含脚本日志、卡包编号/分数/间隔、观测和选择结果、操作前后截图。镜牢奖励模板一旦命中，实验抛出接管信号 `STOP_BEFORE_REWARD`，阻止进入后续领取逻辑；不领取或放弃镜牢结算奖励。

2026-10-08 已记录：Normal 第1层按图片选择1007并进入地图，原脚本完成本层战斗后在第2层接管；Normal 第2层第三排1206、Hard 第2层第四排1321观测成功。初版模板发现细密卡面漏识别，后续补充选包截图模板。最新模板的实机复验记录继续补充，不能把初版导航实验当作最新匹配代码的完整验证。

本功能覆盖 Normal / Hard 第1–5层的观测地图和已采集95种卡包。尚未采集的新卡包需要补充截图与地图；当前没有隐藏卡包或其他难度的素材。地图采集完整性与每种卡包的实机拖动验证是不同的检查范围。
