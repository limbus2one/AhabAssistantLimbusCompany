# 镜牢黑兽浮士德 E.G.O. 释放

## 使用

在队伍的「自定义设置」中启用「黑兽浮士德 Hollow（英文）」。人格须为 Heishou Pack - Mao Branch Agent Faust，装备四阶 Hollow；本次将用户所说的「兔子洞」对应到游戏内 Hollow。普通觉醒卡名为 Le Trou，侵蚀卡名为 Hollow。

- `use_ego`：每场战斗第一次能够排入行动槽时使用一次，默认关闭。资源不足会继续胜率分配，后续回合再试。
- `ego_corrosion`：长按卡头选择侵蚀，默认关闭。关闭时选择普通觉醒。
- `ego_speedup`：识别到 Hollow 全屏动画时，在屏幕中心原地长按两秒，再释放触点并重新识别；默认关闭。可以独立启用以加速手动安排的 Hollow。

已有首回合防御、连续防御和全员防御优先。在指定 E.G.O. 成功排入之前使用胜率分配其他技能；成功后的回合恢复原有避免/优先三技能策略。仅镜牢传入这三个队伍选项。

## 识别与输入

所有 E.G.O. 图片匹配阈值为 0.90，沿用现有模板匹配与分辨率缩放，不添加识别模型或依赖。

1. 先按一次 P 分配普通技能，匹配黑兽浮士德头像。沿胜率分配的青色连线取敌方端点；无法确认目标则本回合跳过 E.G.O.。
2. 原地长按头像 1.2 秒打开面板，匹配英文卡名；需要切换普通/侵蚀时长按卡头，再复核卡名。点击卡面确认，资源不足时收起面板。
3. 展开、收起技能预览，等聚焦战斗的镜头移动后，重新确认敌方端点，再把 E.G.O. 技能拖到目标。单图裁剪匹配的坐标加回裁剪原点，避免点错罪人。
4. 在同一罪人的行动槽匹配 Le Trou 图标或金色 OVERCLOCK 火车头。复核成功才按 Enter；确认后无法复核时抛出异常停止当前操作。一次尝试只按一次 P，避免第二次按 P 撤销分配。
5. 动画加速分别匹配普通标题、侵蚀标题和持续出现的 OVER 标记。普通交战中的长按会减慢播放，因此仅识别到全屏 E.G.O. 动画才长按；开关开启时缩短交战采样间隔。

MuMu 原生输入为零位移拖动保留完整请求时长，使用 `finally` 释放触点。非零位移拖动保持原实现。

## 2026-10-09 实机验证

环境：conda `aalc`，MuMu Global 实例 0，ADB `127.0.0.1:16384`，英文游戏 1.116.2，1920×1080。实际遭遇为 Hard 第五层 Thunder and Lightning 的 Dreaming Electric Sheep 聚焦战斗。

用户授权退出并换装后，先保存镜牢进度，在主界面装备黑兽浮士德与 Hollow IV。恢复镜牢发现开局快照仍是旧人格；随后沿原镜牢流程到商店，使用 Team 功能消耗 100 镜牢金币更新浮士德快照，并再次确认人格与 E.G.O.。整个实验未领取或放弃镜牢结算奖励。

| 普通释放，动画长按 | `release_20261009_193536` | 入槽通过，实际 Le Trou 动画内长按 2.000 秒，`NEXT_PLANNING` 后停止 |

曾试过在所有交战画面长按，实测使普通播放变慢并触发实验时限；已改为仅在 E.G.O. 动画内长按。曾出现技能预览移动镜头后拖到旧位置、重复按 P 撤销分配、Enter 后旧待机截图被重复操作的问题，均依据实机截图修正。早期实验超时不作为完整流程成功的证据。

采样截图中，普通动画标题不加速时持续约 4.78 秒，加速实验约 2.98 秒。截图采样、保存和识别本身有耗时，这仅说明观察到的标题阶段变化，不作为整段动画的精确加速比例。

## 重现实验

从同一遭遇的干净战斗待机页启动；可先使用 Retry Stage 恢复本场初始资源，不要保留手动预先选好的 E.G.O.。实验脚本实际调用原 Mirror/Battle，拦截奖励识别，并在观察到播放之后的下一次待机操作前停止：

```powershell
conda activate aalc
python scripts/verify_ego_release.py --speedup
python scripts/verify_ego_release.py --corrosion --speedup
```

两条命令是两个独立实验，每次之间先 Retry Stage。`--queue-only` 只观察排入，不按 Enter；正常实验最长五分钟。该脚本固定使用 MuMu 实例 0 的 ADB 地址，并在内存副本中关闭两项首轮防御，不保存用户队伍配置。

## 验证范围

已实测英文、1920×1080、该 Hard 第五层聚焦遭遇中的普通与稳定侵蚀释放及动画长按。未验证其他分辨率、非聚焦遭遇、红色不稳定火车头、其他人格或 E.G.O.。人物与敌方位置由实际截图识别，缺少头像或目标连线时跳过。Hollow 已有 Ashen Bullet 后普通卡名会变为 Boucher un trou，目前只有 Le Trou 模板，该变体会跳过；不要把本次结果视为这些场景均已支持。
