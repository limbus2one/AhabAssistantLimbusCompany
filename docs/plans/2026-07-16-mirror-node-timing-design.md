# 镜牢节点停留时间设计

成功进入节点 A 时，以单调时钟记录开始时间。成功进入下一个已识别节点 B 时，计算两次进入时刻之差，并写入节点 A 的 `node_time`；随后从节点 B 重新开始计时。

`Node.node_time` 初始为 `0`，表示尚未进入下一个节点、当前停留时间还未结算。`MirrorMap` 保存当前节点、开始时间和已进入节点历史，确保路线重新识别后，已经进入的节点对象及其耗时仍可读取。

尝试进入下一个节点前，先输出当前节点的 `team_number`、`theme_pack`、`node_time`、节点类型和楼层。成功进入下一节点后再校准最终耗时；如果进入失败，下次尝试时会重新计算当前节点的持续时间。

只有通过已识别路线成功进入的节点才参与记录。无法确认节点对象的兜底寻路不会创建虚假节点。计时使用 `time.monotonic()`，避免系统时间调整影响持续时间。
